
Se utilizo Google Apps Script para analizar datos utilizando una base de datos del DENUE

Con funciones ls(arg)

't': negocios con teléfono
'w': negocios con página web
'c': negocios con correo electrónico
'a': negocios con los tres elementos

#ls_v(tipoVialidad, nombreVialidad)

Muestra los negocios que coinciden con el tipo y nombre de vialidad.

#lsGPS(latitud, longitud)

Obtiene los 5 negocios más cercanos a unas coordenadas dadas, dentro del rango máximo de 3 kilómetros
